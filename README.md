# Set-Theoretic Complete Intersections of Space Curves

Research objective: prove or disprove that every integral closed curve in
projective three-space over an algebraically closed field is the reduced
intersection of two homogeneous surfaces.

The universal problem and the unrestricted characteristic-zero rational
quartic test case remain unresolved in this repository.
