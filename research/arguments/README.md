# Arguments

This directory holds complete mathematical expositions under the
[four-object model](../MODEL.md). The torus pilot has independently reviewed
arguments for [supported Hilbert boundaries](torus_hilbert_boundary.md),
[sextic residuals and full limits](torus_sextic_residuals.md), and
[embedded quotient descent](torus_embedded_quotients.md). Each linked Result
states its exact mathematics and retains its own status; all pilot Results
remain provisional. Existing promoted records and their evidence retain authority.

For authoring use the [Argument template](../../scripts/templates/argument.md).
